# :not(.class){...}: 
Appliquer un style sur certaines types de balises sans la balise avec la classe ".class"

# :nth-child(odd/even){...}:
Appliquer un style aux balises en ciblant celles qui sont paires et celles qui sont impaires.

# :first/last-child{...}:
Appliquer un style sur la premiere/derniere paragraphe (sans utiliser div ou des br pour chaque paragraphe)
